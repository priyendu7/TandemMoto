# Security Policy

## Supported versions

TandemMoto is pre-1.0. Only the latest tagged release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's [private vulnerability reporting](https://github.com/priyendu7/TandemMoto/security/advisories/new). Include affected version, device/Android version, and steps to reproduce.

Areas of particular interest: the Wi-Fi Direct pairing/link protocol, the file-transfer and state-sync sockets, and microphone/audio handling in the foreground service.

You should get an acknowledgement within a week. Fixes will be credited in the release notes unless you prefer otherwise.
